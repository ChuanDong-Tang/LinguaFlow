# OIO 1.0.7 开发计划

更新日期：2026-08-02

## 1. 产品目标

OIO 从 AI 聊天工具转为“个人生活表达库”。本版建立三层体验：

1. 快速笔记：随手记录和快速获得表达，确认有价值后再转为正式 Card。
2. 正式 Card：长期保存、生活集整理、图片、挖空和按需生成。
3. 回忆：通过简单、连续的浏览和练习重新遇见过去的表达。

旧聊天记录继续保留，但作为历史快速笔记，不强制转成 Card，也不再强化聊天心智。

## 2. 当前基线

### 已具备

- Card 创建、AI 改写、图片、搜索、详情、删除和任务轮询。
- 生活集嵌套、收藏、未分类、移动和侧边栏导航。
- Card 查词、挖空、填空、听写、TTS 和练习状态。
- Topic、Phrase、Progress 三类关系及 Recall Session 后端能力。
- Card 全员云端存储，旧 Chat/Message 接口继续兼容老客户端。

### 当前问题

- 移动端页面过大：`App.tsx`、`MainScreen.tsx`、`CardDetailModal.tsx` 混合了导航、请求和大量业务状态。
- 当前只有一份 Card 草稿，不支持一天内多条快速笔记。
- Card 创建后必经改写，尚不支持直接导入已完成表达。
- Card 只支持一张图片。
- 翻译和回复尚不是按需生成的独立内容。
- 当前 Recall 前端偏重关系蓝图，不适合作为首版回忆入口。
- 当前逐词填空呈现与新版“一个选区、一个空”方向不一致。

## 3. 本版范围

### P0：稳定当前检查点

- 整理并提交当前 Card、生活集、搜索、图片、练习和样式改动。
- 修复重复删除弹窗、残留视图状态和已知交互问题。
- 完成 Mobile TypeScript、Prisma、diff check 和 iOS 真机回归。

### P1：移动端结构整理

- 将首页拆为 Library、CardList、Sidebar、QuickCapture。
- 将详情拆为 CardEditor、CardReader、CardToolbar、Practice、Media。
- 抽离 Card 创建轮询、媒体上传和生活集操作逻辑。
- 按 cards、collections、practice、recall、media 拆分 API 封装。
- 保留当前导航行为，先解决职责混杂，不同时引入大型导航改造。

### P2：快速笔记 MVP

- 首页悬浮按钮一步进入快速笔记。
- 支持保存多条轻量草稿，并按当天集中回看。
- 快速笔记不使用聊天气泡，不营造 AI 对话感。
- 每条支持改写、复制、删除和一键转正式 Card。
- 旧聊天记录进入独立历史入口，暂不强制迁移。
- 第一版本地优先、账号隔离；云同步另行确认。

### P3：Card 创建与按需能力

- 支持“原文 → AI 改写”创建 Card。
- 支持快速笔记携带已有表达直接转 Card，避免重复生成。
- 支持用户直接导入已经满意的目标语言内容。
- 翻译和回复默认不生成，从底部工具栏按需触发并保存。
- 明确生成结果的编辑、重试和删除规则。

### P4：新版填空

- 用户可选择单词、短语或中文字符范围。
- 选区落在单词中间时自动扩展到完整单词边界。
- 一个选区整体显示为一个空，并使用一个输入框作答。
- 用小点或弱提示表达词数/字数，不拆成多个输入框。
- 保留眼睛按钮偷看答案、长按编辑、查词和删除。
- 已有挖空影响正文编辑时，先提示清除相关挖空。

### P5：简单回忆 MVP

- 支持系统随机推荐或用户选择第一张 Card。
- 使用上一张/下一张的线性浏览，不先展示关系图。
- 每张可直接回看、填空或听写。
- 使用现有关系服务推荐下一张相关 Card。
- 详情仅在存在高质量关系时显示一张“相关生活”彩蛋。
- 现有 Recall 蓝图后端保留，复杂图谱前端延后。

### P6：UI 调整

- 首页缩略图移动到左侧，文字放右侧。
- 详情保持日期、图片、目标语言表达、用户原文的顺序。
- 底部工具栏按右手高频操作重新排序。
- 统一快速笔记、Card 和回忆的字体、颜色、间距与空状态。

## 4. 需要服务端配合的项目

- 多图：当前 Card 与图片是一对一关系，需要改为一对多及调整上传接口。
- 按需翻译/回复：需要独立内容字段或产物表、生成任务和接口。
- 直接导入/转 Card：需要允许已有目标表达直接完成 Card，避免重复 AI 改写。

新版整段填空可继续使用当前 Card 的连续字符范围结构，首版不要求修改数据库。

## 5. 本版明确延后

- 关系蓝图正式开放和游戏化回忆。
- 微信或其他外部平台快速导入。
- 左撇子模式。
- 多标签、自由拖动和无限复杂的生活集管理。
- 自动为所有 Card 生成翻译与回复。
- 为改版而删除旧 Chat/Message 数据和兼容接口。

## 6. 发布顺序

1. 当前工作区形成可回退的稳定提交。
2. 完成结构整理和快速笔记。
3. 完成整段填空和简单回忆。
4. 完成 UI 真机打磨及数据兼容验证。
5. 再评估多图和按需翻译/回复是否进入 1.0.7，避免阻塞核心版本。

## 7. 验收标准

- 新用户不会把首页和快速笔记理解成聊天软件。
- 随手记录到获得改写最多一步进入，转 Card 不重复输入。
- 单词、英文短语和中文词组都能作为一个空完成练习。
- 用户可以从任意 Card 开始一段连续回忆并正常返回。
- 1000 条 Card 下列表仍使用分页和虚拟化方案，不一次性渲染全部内容。
- 旧用户的聊天记录、会员能力和 Card 数据均不丢失。
