# 进行中的产品任务

这里仅存放已经确定实施，并进入需求设计、开发或验证阶段的产品任务。

## 进入条件

任务移入本目录前，至少需要明确：

- 要解决的用户问题和预期结果；
- 第一版范围与明确不做的内容；
- 关键交互或业务规则；
- 主要数据、隐私和兼容性边界；
- 验收标准；
- 已确认开始实施，而不只是认为方向可行。

## 当前任务

## 完成后的处理

功能完成后，不把本目录当作永久事实来源：

- 长期有效的产品规则更新到正式业务文档；
- 架构与调用链更新到架构或业务流程文档；
- 阶段性设计和实施记录移入对应版本目录或保留为历史决策；
- 同步更新上级 [`product/README.md`](../README.md) 的状态索引。
