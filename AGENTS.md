# Repository agent instructions

For broad LinguaFlow maintenance, project status, handoff, or work spanning
multiple domains, read and follow
`skills/linguaflow-daily-operations/SKILL.md` before acting.

For feature development or bug fixing, read and follow
`skills/linguaflow-feature-delivery/SKILL.md` before acting.

For production symptoms, user-specific live issues, task failures, or version
drift diagnosis, read and follow
`skills/linguaflow-production-incident/SKILL.md` before acting.

For backend push/pull rollout, deployment, or API/Worker restart requests, read
and follow `skills/linguaflow-backend-deploy/SKILL.md` before acting.

For iOS, Android, TestFlight, Google Play, China APK, OTA, packaging,
validation, upload, or store submission requests, read and follow
`skills/linguaflow-android-release/SKILL.md` before acting. The Skill's public
name is `linguaflow-app-release`; the existing directory name is retained for
script compatibility.

For production database deployment, migration, Prisma runtime mismatch, or
database-backed persistence diagnosis, read and follow
`skills/linguaflow-production-database/SKILL.md` before acting.

For Apple, Google Play, Alipay, manual membership, entitlement, plan change,
purchase verification, transfer, cancellation, reconciliation, or payment
audit requests, read and follow
`skills/linguaflow-subscription-operations/SKILL.md` before acting.

For Card rewrite, alignment, auxiliary content, image description, prompt/job
version, retry, scanner, or backfill requests, read and follow
`skills/linguaflow-card-ai-pipeline/SKILL.md` before acting.

For Mobile, API, database, Worker, provider, or end-to-end performance work,
including P90/P95/P99, startup, slow queries, connection pools, queue delay,
tracing, or regressions, read and follow
`skills/linguaflow-performance-engineering/SKILL.md` before acting.
